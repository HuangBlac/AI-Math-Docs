# 工业计算：从几何建模到并行求解

工业软件中的一次数值仿真，通常不是单独调用某个算法，而是一条连续的数据与计算链：

```text
CAD 几何模型
  -> 网格与离散空间
  -> 变分问题或控制方程
  -> 稀疏线性/非线性方程组
  -> 并行求解与后处理
```

本专题由三份扫描手写笔记整理而来。原笔记跨度较大，因此按实际主题拆成三篇，而不是机械地按 PDF 文件拆分。

## 三个主题之间的关系

CAD 决定几何域，有限元决定如何在该几何域上离散方程，并行计算决定怎样更快地装配和求解离散系统。逆问题与高维计算则说明：即使离散和求解过程成立，问题仍可能因噪声放大或维数增长而不可直接计算。前三者的接口主要是两类数据：

- **网格数据**：节点、单元、邻接关系、边界标记；
- **代数数据**：稀疏矩阵 $A$、未知向量 $x$ 和右端项 $b$。

因此，工业仿真的核心常被概括为：

```math
\text{geometry} \longrightarrow \text{mesh} \longrightarrow
\text{discretization} \longrightarrow Ax=b \longrightarrow \text{solution}.
```

这里最值得建立的认识不是记住软件名称，而是明白：几何表示、离散误差、矩阵条件数、数据布局和并行通信会共同决定最终结果是否可靠、是否算得动。
