## 1. 一维热方程：稳定性比格式名称更重要

考虑

```math
u_t=u_{xx}+\sin t,
\quad 0<x<1,
\qquad
u_x(t,0)=u_x(t,1)=0,
```

初值与精确解为

```math
u(x,0)=\cos(\pi x),
\qquad
u(x,t)=e^{-\pi^2t}\cos(\pi x)+1-\cos t.
```

令

```math
r=\frac{\tau}{h^2}.
```

实验比较三类格式：

- 向前显式格式：每一步直接由旧时间层计算，稳定区间要求 $r\le1/2$；
- 向后隐式格式：每一步求解线性系统，对该模型无显式格式那样的 CFL 限制；
- Crank-Nicolson 格式：时间上取梯形平均，兼顾隐式稳定性和二阶时间精度。

PDF 记录的 $t=1$ 采样结果显示：

| 格式与网格 | $r$ | 采样点最大绝对误差 | 现象 |
|---|---:|---:|---|
| 显式，$h=1/40,\tau=1/3200$ | $0.5$ | 约 $1.32\times10^{-4}$ | 稳定 |
| 显式，$h=1/80,\tau=1/12800$ | $0.5$ | 约 $3.3\times10^{-5}$ | 网格减半后误差约缩小四倍 |
| 显式，$h=1/80,\tau=1/3200$ | $2$ | 第 40 步已到 $10^{17}$ 量级 | 违反稳定条件后爆炸 |
| 隐式，$h=1/40,\tau=1/1600$ | $1$ | 约 $2.65\times10^{-4}$ | 稳定但更耗散 |
| 隐式，$h=1/80,\tau=1/3200$ | $2$ | 约 $1.32\times10^{-4}$ | 大 $r$ 下仍稳定 |
| Crank-Nicolson，两组网格 | $1,2$ | 六位小数下显示为 $0$ | 记录精度内与真解非常接近 |

“显示为零”只说明误差小于表格的六位小数分辨率，不能据此声称误差严格为零。

## 2. 二维抛物方程：从整矩阵到方向分裂

第二个实验考虑

```math
u_t=\frac1{16}(u_{xx}+u_{yy}),
\qquad
(x,y)\in(0,1)^2,
```

配合 $x$ 方向齐次 Dirichlet 边界、$y$ 方向复制型离散 Neumann 边界，以及初值

```math
u(x,y,0)=\sin(\pi x)\cos(\pi y).
```

精确解为

```math
u(x,y,t)=\sin(\pi x)\cos(\pi y)e^{-\pi^2t/8}.
```

实验比较：

- **Crank-Nicolson**：把二维离散 Laplace 算子组成一个大稀疏矩阵并整体求解；
- **ADI**：把一个二维隐式步拆成 $x$、$y$ 两个一维方向求解；
- **预校法**：先显式预测，再用新旧离散算子平均校正；
- **LOD**：按方向依次执行局部一维隐式步骤。

在 $h=1/40,\tau=1/1600,t=1$ 的九个采样点上，PDF 记录的最大绝对误差为：

| 方法 | 采样点最大绝对误差 |
|---|---:|
| Crank-Nicolson | $0.005019$ |
| ADI | $0.005019$ |
| 预校法 | $0.005019$ |
| LOD | $0.004969$ |

这些单网格结果只能比较当前设置下的数值表现。源码还会在 $N=20,40,80$ 上计算无穷范数误差和经验收敛阶，但 PDF 没有保存最终阶数表，因此这里不补写未实际看到的数值。

## 3. 为什么方向分裂适合工业计算

二维隐式格式若直接求解，会形成 Kronecker 和结构的大型稀疏系统。ADI 与 LOD 利用坐标方向可分性，把二维问题化成多组一维带状系统：

- 单次求解更便宜；
- 内存访问更规则；
- 不同网格线之间具有并行机会；
- 代价是引入分裂误差，并且复杂几何下不一定仍能保持这种简单结构。

这正是工业计算页面中“离散结构决定求解器与硬件映射”的具体例子。
