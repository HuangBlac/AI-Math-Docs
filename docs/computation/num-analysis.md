## 快速傅里叶变换：从定义到分治

长度为 $N$ 的离散傅里叶变换为

```math
X_k=\sum_{j=0}^{N-1}x_j\omega_N^{jk},
\qquad
\omega_N=e^{-2\pi i/N}.
```

直接计算所有 $X_k$ 需要 $O(N^2)$ 次运算。若 $N$ 为偶数，把输入按奇偶下标拆开：

```math
X_k
=\sum_{r=0}^{N/2-1}x_{2r}\omega_{N/2}^{rk}
+\omega_N^k\sum_{r=0}^{N/2-1}x_{2r+1}\omega_{N/2}^{rk}.
```

右侧是两个长度 $N/2$ 的 DFT。利用 $X_{k+N/2}$ 与 $X_k$ 共享这两个子问题，得到递归

```math
T(N)=2T(N/2)+O(N),
```

因而

```math
T(N)=O(N\log N).
```

FFT 改变的是计算同一个 DFT 的方式，不是新的变换。它也不等同于压缩感知：FFT 利用 Fourier 矩阵的递归结构加速完整变换；压缩感知利用信号在某个基下的稀疏性，从少量测量恢复信号。
